# calculator

🧮 Python Calculator

A simple terminal-based calculator built with Python.

✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Power calculation
- Square root
- Percentage calculation
- Input validation
- Division by zero handling
- Negative square root handling
- Simple and user-friendly terminal interface

🛠️ Technologies

- Python
- Python "math" module

▶️ How to Run

1. Install Python on your computer.
2. Clone the repository:
   git clone YOUR_REPOSITORY_LINK
3. Open the project folder:
   cd python-calculator
4. Run the program:
   python calculator.py

🧑‍💻 How It Works

The program displays a menu with different mathematical operations.
The user selects an operation and enters the required numbers.

The calculator validates the input and handles common errors such as division by zero and invalid square root values.
